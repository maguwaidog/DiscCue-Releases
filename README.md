# DiscCue

DiscCue is a Windows subtitle projection application that displays user-provided SRT subtitle files on a separate display or projector.

## Download

Download the latest installer from [GitHub Releases](https://github.com/maguwaidog/DiscCue-Releases/releases/latest).

## DiscCue Standard

- ¥2,480 one-time purchase
- Up to 2 activated devices
- No subscription
- Offline use after initial online activation

## Important

DiscCue does not include or distribute movies, TV programs, Blu-ray/UHD content, or third-party subtitle files.

Users provide their own media and subtitle files.
